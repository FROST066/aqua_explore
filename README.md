## 📖 À propos

**AquaExplore** est une application mobile révolutionnaire développée dans le cadre du *NASA Space Apps Challenge* (Team **EcoSentinels**). Notre mission est de relever le défi crucial de la préservation des rivières et des écosystèmes aquatiques.

En intégrant des **données de pointe de la NASA** et des technologies de télédétection, AquaExplore offre une analyse approfondie de la qualité de l'eau et de la biodiversité, rendue accessible via une interface utilisateur intuitive. Nous transformons les utilisateurs en gardiens responsables de leurs écosystèmes locaux.

> 💡 *Water is life — understanding it is the first step to protecting it.*

## ✨ Fonctionnalités Clés

AquaExplore combine innovation, éducation et collaboration communautaire :

* 🗺️ **Carte Interactive** : Visualisez les cours d'eau autour de vous avec des données en temps réel.
* 💧 **Qualité de l'Eau** : Accédez à des analyses détaillées sur la pollution et la santé des rivières basées sur des données satellites.
* 🐟 **Biodiversité & Espèces** : Identifiez les espèces vivant dans les cours d'eau et recevez des notifications sur les espèces menacées.
* 🎓 **Quiz Éducatifs** : Apprenez en vous amusant pour mieux comprendre les enjeux environnementaux.
* 🤝 **Communauté Collaborative** : Signalez des problèmes, partagez des observations et engagez-vous activement.

## 🛠️ Stack Technique

Ce projet s'appuie sur des technologies modernes et des données scientifiques fiables :

* **Données :** NASA Open Data (Télédétection, Satellite Imagery)
* **Mobile :** Flutter
* **Backend :** Nestjs ([Link](https://github.com/eliotfgn/aquaexplore-backend))

## 🚀 Installation et Démarrage

Pour exécuter ce projet localement sur votre machine, suivez ces étapes :

### Prérequis
* Git
* Flutter SDK / Android Studio

### Étapes
1.  **Cloner le dépôt**
    ```bash
    git clone https://github.com/FROST066/aqua_explore.git
    cd aqua_explore
    ```

2.  **Installer les dépendances**
    ```bash
    flutter pub get
    ```

3.  **Lancer l'application**
    ```bash
    flutter run
    ```
